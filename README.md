# 吃了么

> 今天，也好好吃饭。

「吃了么」是一个为手机设计的家常菜谱 App：每天按口味、人数和菜品数量配好一桌菜，固定带一道汤；菜谱有精确用量和详细步骤，支持搜索、收藏和采购清单，完全离线可用。

## 功能

- **今日推荐**：每日菜单按日期稳定生成，默认「三菜一汤」，可一键「换一桌」。
- **口味与人数**：清淡、香辣、酸甜、家常、不限；1～8 人；1～5 道菜（不含汤，固定配 1 道汤）。
- **默认设置**：在「我的」里修改默认口味、菜数、人数和忌口，之后每天按新默认推荐。
- **多做法菜谱**：27 道菜、61 种做法，每道菜至少 2 种做法（经典 / 快手 / 少油等）。
- **精确内容**：每份做法含食材克数或毫升数、分组、处理备注、分步火候与时间、关键技巧、过敏原提示。
- **搜索**：按菜名、别名、食材、口味、做法名搜索；支持荤菜 / 素菜 / 汤羹 / 主食筛选。
- **人份换算**：食材用量随人数自动换算，采购清单按整桌菜单汇总并去重。
- **采购清单**：勾选已买食材，状态保存在本机，可一键复制。
- **烹饪模式**：全屏逐步引导，可查看本菜用料和关键提示。
- **收藏**：收藏喜欢的菜，在「我的」里快速找到。
- **离线**：菜谱、搜索、推荐全部在本地完成，无账号、无广告、无网络请求。

## 两种使用方式

### 方式一：单文件离线版（最简单）

文件：`吃了么-离线版.html`

1. 把文件传到手机（微信文件传输助手、数据线、网盘均可）。
2. 用手机浏览器打开它。
3. 所有菜谱都内置在这一个文件里，断网也能看、能搜、能推荐。

注意：通过 `file://` 打开时，浏览器不允许注册 Service Worker，所以不能「安装成独立 App」；但核心功能完全离线可用。iPhone 上可点 Safari 分享 →「添加到主屏幕」，作为网页快捷方式使用。

### 方式二：PWA 安装版（推荐，像 App 一样）

文件：`chileme-pwa.zip`（解压后是静态网站）

1. 把解压后的整个文件夹部署到任意 **HTTPS** 静态网站（GitHub Pages、Netlify、Vercel、Cloudflare Pages、对象存储等均可）。
2. 手机浏览器打开部署后的网址。
3. Android Chrome：右上角菜单 →「安装应用」/「添加到主屏幕」。
4. iPhone Safari：分享按钮 →「添加到主屏幕」。
5. 首次打开会缓存应用，之后断网也能从桌面打开。

> 本地预览可用 `python -m http.server 8123`，然后访问 `http://localhost:8123`。局域网 IP 的 HTTP 地址不支持 Service Worker，手机安装请使用 HTTPS。

## 默认设置

首次打开为：口味「不限」、3 道菜、2 人、含 1 道汤、无忌口。

在「我的 → 默认推荐」中修改后，会立即重新搭配今日菜单；点「恢复默认」可还原。今日临时调整可在首页点「调整」，只影响当天。

## 数据与隐私

- 收藏、默认设置、采购勾选只保存在浏览器 `localStorage`，不会上传。
- 没有账号、统计、广告或第三方请求。
- 清除浏览器数据会同时清除收藏和设置。

## 菜谱说明

- 菜谱为家常做法参考，用量按 2～3 人基础份量编写；详情页会按所选人数换算。
- 步骤文字中的用量按该做法的基础份量标注，人数变化后请以食材表为准；份量加大时适当延长加热时间。
- 生熟分开、肉类彻底加热（鸡肉中心约 75℃）、四季豆完全熟透。
- 过敏原提示为自动识别，仅供提醒；严重过敏请以实际购买产品的配料表为准。

## 目录结构

```
chileme/
├─ index.html                 PWA 入口
├─ manifest.webmanifest       PWA 配置
├─ sw.js                      离线缓存
├─ assets/
│  ├─ styles.css
│  ├─ app.js                  应用逻辑
│  ├─ data-meat-1.js          菜谱数据（荤菜）
│  ├─ data-meat-2.js          菜谱数据（荤菜）
│  ├─ data-veg.js             菜谱数据（素菜）
│  ├─ data-soup.js            菜谱数据（汤羹）
│  ├─ data-staple.js          菜谱数据（主食）
│  └─ logo.svg
├─ icons/                     App 图标
├─ tools/                     本地构建与测试脚本（不参与发布）
└─ README.md
```

## 本地构建

```bash
python tools/build.py
```

会生成：

- `dist/吃了么-离线版.html`
- `dist/chileme-pwa.zip`
